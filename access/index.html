01 / Connect. Pick a pane. See the file.

The remote machine,
right in your terminal.

Connect to leibo-asus with aih remote leibo-asus pane. Choose a pane in the picker, open the SSH shell, then view the image named in its command output.

One command to your panes

aih remote leibo-asus pane

Choose the session you want to follow. Its output stays on the remote machine and appears in your terminal.

Open the image it mentions

In the pane viewer, press Ctrl + ], then f to browse the remote files. Choose the image named in the shell output and press Enter. Press any key to close the image.

Video transcript

Connect to the paired machine leibo-asus. Choose the remote session in the pane picker. Open the demo SSH shell, which names a PNG on the remote machine. Use Ctrl-] then f to browse remote files and view that image inside the terminal.

02 / Files become bubbles

From a file name
to its contents.

Your remote shell mentions preview.png and NOTES.md. Open the pane's bubbles and choose a file to preview it, without browsing through directories.

Open the bubbles

In the pane viewer, press Ctrl + ], then b. Detected files appear as numbered bubbles. Press the number beside the file you want to open.

Preview, then carry on

Images open inside the terminal; Markdown opens in the text pager. Press any key to close an image, or q to leave the pager. Back in the bubbles, press q to return to your pane.

Video transcript

A remote shell lists preview.png and NOTES.md. Open the bubbles with Ctrl-] then b. Select preview.png to view the image. Return to the bubbles and select NOTES.md to read its Markdown contents. Close the preview and return to the same pane.

03 / Internet off. Internet back. Same shell.

A dropped connection.
An uninterrupted session.

Start an SSH shell, disconnect the internet, and watch the red connection banner appear. Restore the internet and continue with the same shell, process ID, and shell variable.

Your usual SSH client

aih ssh leibo-asus

AIHerd uses OpenSSH. At the beginning of a new line, type ~? to see its standard escape help, as shown in the video.

Pick up when the network returns

The banner tells you when the connection is stalled and retrying. When connectivity returns, the existing session resumes. The remote machine and its herd must keep running.

Video transcript

Open an SSH shell on leibo-asus and record its process ID and a shell variable. Type ~? on a new line to show OpenSSH escape help. Turn off the internet connection. The red AIHerd banner reports the stalled connection. Restore the internet, then print the process ID and variable again: both survive in the same shell.

04 / Bring your SSH-compatible client

Cyberduck.
Same remote files.

Open a local SSH listener for a paired herd. SSH-compatible clients can connect to it like an SSH server, while AIHerd carries the connection to leibo-asus.

1. Start the listener

aih ssh leibo-asus --listen 127.0.0.1:2222

Leave this command running on the same computer as Cyberduck. It prints the local address it is listening on. If port 2222 is busy, choose another port and use that port in your client.

2. Open a Cyberduck connection

Choose Open Connection and enter:

Cyberduck settings for this listener
ProtocolSFTP (SSH File Transfer Protocol)
Server127.0.0.1
Port2222
Usernameaih
PasswordLeave empty
SSH private keyNone required

Click Connect to browse the remote machine's files. The remote herd needs an SFTP server available. See Cyberduck's SFTP documentation ↗.

Use the same listener with OpenSSH

ssh -p 2222 aih@127.0.0.1
sftp -P 2222 aih@127.0.0.1

The address belongs to your local computer. Commands and file operations run on the paired remote machine.

Let AIHerd choose the port

aih ssh leibo-asus --listen

Without an address, AIHerd binds to an available port on 127.0.0.1 and prints it. Enter that printed port in Cyberduck.

Invite a headless Linux machine.

Add a Linux server or container to your AIHerd account without opening a browser on it. Herd invites are available in AIHerd 6.0.2 and later.

Create the invite

Run this in a terminal on a machine whose herd is running, signed in, and connected to its relay.

aih invite --name build-box

Keep this terminal open. The command prints a Linux install command with a one-time invite that expires after 10 minutes.

Run the installer and approve the PIN

Paste the printed command into the new Linux machine’s terminal. When it displays a PIN, enter it at the prompt in the terminal where you ran aih invite.

On Linux without systemd, the installer starts AIHerd in the foreground. Keep that process running to maintain access.

Once the new herd connects, it appears in your account. On the inviting machine, use the saved connection name with aih ssh, for example aih ssh build-box. Run aih connection list to check the name.

Devices already paired with the inviting herd through your account can connect without another PIN. Pair QR-only devices with the new herd.
