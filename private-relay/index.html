AIHerd

Install a private Linux relay

Connect the Linux host to your tailnet, then run this command as the user who will own the relay.

curl -fsSLo install-relay.sh https://aiherd.dev/install-relay.sh && bash install-relay.sh

Supports x86-64 and ARM64 Linux with a systemd user session, Tailscale, Bash, curl and Python 3. Enable MagicDNS and HTTPS certificates on the tailnet.

Connect a herd

The installer prints the private HTTPS origin and the path to genesis.json. Give this public profile to the person configuring your organization’s herd. It contains the relay’s public key and tailnet name. Back up the adjacent relay.key privately on the server.

A new installation generates a new relay identity. For a relay move, restore the original identity/ directory under ~/.local/share/aih-relay/ before installing, then run aih org-relay set NEW_HTTPS_ORIGIN on the herd and restart it.

Operate the service

The relay listens on 127.0.0.1:18787. Tailscale Serve provides HTTPS on the node’s MagicDNS name at port 443. If another service owns either port, choose free ones on the first install with --https-port 9443 --listen-port 18788. The installer preserves existing Serve routes and refuses a port configured for Funnel.

systemctl --user status aih-relay.service
journalctl --user -u aih-relay.service -n 50

To keep the user service running after logout and start it at boot, enable lingering with loginctl enable-linger "$USER". On systems that restrict Tailscale configuration, the installer prints the exact operator command to run. Repeating the install keeps the existing key and profile.
